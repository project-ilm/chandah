# CONTRACT: chandah

This overlay adds to the master contract at zistgah/governance and never relaxes it. Where the two differ, the master
wins. Each clause names the check in `ops/verify.sh` (V01 to V06) that enforces it and what earned it.

**K1. Hindawi builds; nothing here simulates a build.**
A compile check either runs Hindawi or refuses. Enforced by V01 (a test runs the check without Hindawi and requires a
refusal). Earned by the given `ensure_compiles`, which returned a fixed answer whatever the program.

**K2. The given code is kept as given.**
Only the copyright lines and the corrections in docs/CORRECTIONS.md differ from the given restore script. Enforced by V02,
which re-derives `sutram_tool/` with `ops/from_given.py` and compares it byte for byte. Earned by C47.

**K3. A program v11 does not cover is refused by name, never half-converted.**
Enforced by V01 (the notebook's C++ program is refused, with the parser's reason).

**K4. Every layer is checked on the way back.**
A layer that does not bring back the base sutram and the program's parse tree is reported as not coming back. Enforced by
V01 (the notebook's program through every layer and every katapayadi combination).

**K5. Hindawi's keywords are the canon.**
The words v11 uses for keywords, types and the preprocessor are Hindawi's Sanskrit bindings, kept as written. Enforced by
V01. Earned by C47 and by the HTML manual, whose word for `return` was not Hindawi's.

**K6. The notebook is Hindawi's Sanskrit notebook with chandah added.**
Every given cell is in it, unchanged and in order. Enforced by V03. Earned by the author's instruction of 23 October 2026.

**K7. Nothing here carries invisible characters outside a script's own spelling.** Enforced by V04. Earned by C48.

**K8. The notices travel.** Enforced by V01 (`--version`, `--help`) and V05. Earned by C45.

Reconstruct faithfully. Critique with evidence, not tone. Maintain contract and context.
