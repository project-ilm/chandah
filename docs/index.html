chandah

C and C++, in any language Hindawi supports, raised to chandah through the sutram layers, lowered back to compilable form, and built and run by Hindawi.

One short word for every symbol, katapayadi numerals, samasa, sandhi and chhandas; every C and C++ sample of Hindawi 2026.10's galleries, in all eleven languages, goes through all 26 paths and back.

pip install chandah-ilm
chandah raise prog.c --lang sanskrit --structure chhandas_anushtubh --sandhi
chandah lower prog.c.chandah
chandah run prog.c.chandah
chandah cc --lang sanskrit -o prog prog.c.chandah
chandah build project.chandah --lang sanskrit
