chandah

Sanskrit C, as Hindawi writes it, through the sutram layers to chandas and back, built and run by Hindawi.

Every layer (words, katapayadi numerals, samasa, sandhi, chhandas) is checked on the way back, and Hindawi builds and runs the original and the reverted program so their outputs can be compared. The layers are sutram v11, written by Meta AI under the direction of Abhishek Choudhary, with basic corrections.

pip install chandah-ilm
chandah stages program.c
chandah revert program.c
