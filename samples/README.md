# Samples

© 1993–2026 Abhishek Choudhary. All rights reserved. AyeAI.

- `gallery/<language>/`: every C and C++ program in Hindawi 2026.10's galleries (hindawiai/hindawi2026.10@b53530f,
  `docs/hindawi/samples/<language>`), eleven languages, the programs the IDE offers by section.
- `practice/`: the two programs of the Sanskrit notebook's C and C++ practice sections.

- `BLASchandah/`: OpenBLAS, ingested by BURP into Sanskrit (wholly Devanagari but for its licence text and the names
  of the system it builds on) and raised to chandah; `chandah build samples/BLASchandah --lang sanskrit` builds it
  (BUILD.md beside it says how it was built and tested).

Each gallery and practice program goes through every path of chandah and back exactly, and Hindawi builds and runs the
original and the lowered program with the same output (docs/MANUAL.md, Measured).
